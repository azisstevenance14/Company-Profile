🚀 TechCorp - Professional Landing Page

Selamat datang di repository TechCorp Landing Page! Project ini adalah website landing page modern, responsif, dan elegan yang dirancang untuk perusahaan penyedia layanan teknologi, perangkat lunak, dan rekayasa teknik.

📸 Fitur Utama

Hero Section Modern: Tampilan latar belakang dinamis dengan teks overlay yang jelas dan responsif.

Navbar Transparan (Glassmorphism): Menu navigasi responsif yang melayang (fixed-top) dengan efek buram yang estetik.

Section Layanan Unggulan: Card interaktif dengan efek hover glow untuk menampilkan bidang project unggulan:

💻 Web Development

🤖 Internet of Things (IoT)

⚡ Electrical Engineering

🛡️ Cyber Security

Formulir Kontak Modern: Area Contact Us bergaya dark mode dengan bidang pemetaan project lengkap.

Footer & Social Links: Tautan media sosial (Instagram, Facebook, GitHub) dan hak cipta terintegrasi.

Fully Responsive: Tampilan optimal di perangkat HP, tablet, maupun layar PC/laptop.

🛠️ Teknologi yang Digunakan

HTML5 - Struktur konten semantik

CSS3 - Custom styling, Flexbox, & CSS variables

Bootstrap 5.3 - Framework CSS untuk tata letak responsif

Bootstrap Icons - Icon vektor modern

Google Fonts - Typography menggunakan font Poppins
